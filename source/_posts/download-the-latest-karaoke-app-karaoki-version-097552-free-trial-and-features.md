**Karaoki public beta version 0.9.7558 is available for download (below) and includes a change to how singer history is stored and various bug fixes.**

[New Aria Blue Skin | Click for Larger Image ![Aria Blue Skin for Karaoki Karaoke Software](https://i2.wp.com/pcdj.com/wp-content/uploads/2019/04/karaoki-newskin-ariablue.jpg?fit=300%2C194&ssl=1 "Aria Blue Skin for Karaoki Karaoke Software")](https://i2.wp.com/pcdj.com/wp-content/uploads/2019/04/karaoki-newskin-ariablue.jpg?fit=1030%2C668&ssl=1)

A new public beta of Karaoki is available for download. While largely a maintenance release, one notable change is how Karaoki stores singer/song history: Instead of one massive running log, history is segmented and stored by Month instead. This change will prevent memory related issues for karaoke hosts with massive singer history databases. The location of history files has also been moved to the PCDJ Karaoki folder located in Documents.

An issue with saving changes done within a session has also been addressed. The fix will allow KJs to delete tracks from within a case again — the songs will remain deleted upon restarting Karaoki.

Please download/install Karaoki version 0.9.7558 below with your existing version closed to update now. If you have feedback feel free to post in the comments section below or on the [PCDJ Facebook User Group](https://www.facebook.com/groups/208451843303338/).

### Changes In Karaoki Beta 0.9.7558

* **Change** – History now saves by Month, “Today” filter added to current months history. The history files are now located in the “Documents>PCDJ Karaoki>History” folder. (this is to help with large history files, which in prior versions could cause resource related problems over time)
* **Fixed** – Karaoki not reloading Disk-ID data from saved singers.
* **Fixed** – Not saving cases on exit (including deleting songs from a case)
* **Possible Fix** – Changes to SSL code for [Karaoke Cloud Pro](https://tools.techidaily.com/pcdj/products/).
